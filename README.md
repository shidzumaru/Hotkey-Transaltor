# Hotkey Translator

Выделяете текст в любой программе → нажимаете горячую клавишу → получаете перевод
во всплывающем окне или прямо на месте выделенного текста. Открытый код (лицензия MIT),
Windows / macOS / Linux (X11).

## Как получить готовый .exe (без установки Python)

Exe собирает GitHub автоматически, это бесплатно:

1. Зарегистрируйтесь на github.com и создайте новый репозиторий (**New repository**).
2. Загрузите в него все файлы из этой папки, включая скрытую папку `.github`
   (если она не загрузилась перетаскиванием, создайте файл через **Add file → Create new file**,
   назовите его `.github/workflows/build.yml` и вставьте содержимое из этого файла).
3. Откройте вкладку **Actions**, выберите **Build Windows exe** и нажмите **Run workflow**
   (сборка идёт 2–3 минуты, и она же запускается при каждом коммите).
4. Откройте завершённый запуск и скачайте в разделе **Artifacts** файл `HotkeyTranslator-windows` (zip с exe внутри).

Если создать тег вида `v1.0`, exe прикрепится к странице **Releases**, и его можно будет скачивать оттуда.

Windows SmartScreen или антивирус могут ругаться на неподписанный exe, который перехватывает клавиши. Это типично для PyInstaller. Нажмите «Подробнее → Выполнить в любом случае» или проверьте код, он открытый.

## Использование

Запустите `HotkeyTranslator.exe`. При первом запуске откроется окно настроек, дальше программа живёт в трее (правый клик по иконке → Настройки / Выход).

В настройках можно добавлять, менять и удалять горячие клавиши. Нажмите **Записать**, затем нажмите нужную комбинацию, и она сохранится сама. Для каждой клавиши отдельно выбираются язык, переводчик и результат: окно или замена выделенного текста. На вкладке «Переводчики и ключи» вводятся API-ключи. Есть галочка автозапуска с Windows. Настройки лежат в `config.json` рядом с exe.

## Запуск из исходников (по желанию)

```bash
pip install -r requirements.txt
python translator.py
```
На Linux: `sudo apt install python3-tk xclip`. На macOS нужны права «Универсальный доступ» и «Мониторинг ввода».

## Провайдеры

| Имя | Ключ | Примечание |
|---|---|---|
| `google_free` | не нужен | неофициальный endpoint Google, по умолчанию |
| `google_cloud` | `GOOGLE_TRANSLATE_KEY` | официальный API |
| `deepl` | `DEEPL_API_KEY` | Free и Pro (Free-ключ заканчивается на `:fx`) |
| `libretranslate` | опционально | открытый, можно свой сервер |
| `openai` | `OPENAI_API_KEY` | любой OpenAI-совместимый API; для Ollama/LM Studio поменяйте `base_url` |
| `anthropic` | `ANTHROPIC_API_KEY` | Claude |

Ключи вводятся в окне настроек. Как запасной вариант читаются и переменные окружения (`DEEPL_API_KEY`, `ANTHROPIC_API_KEY` и т.д.).

## Добавить свой переводчик

В `providers.py` создайте класс:

```python
@register
class MyTranslator(Provider):
    name = "my_translator"
    def translate(self, text, target, source=None):
        ...  # вернуть переведённую строку
```

и он появится в списке переводчиков в настройках.

## Ограничения

- Linux Wayland ограничивает глобальные хоткеи, используйте сессию X11.
- Если комбинация уже занята другой программой, запишите другую в настройках.
- Бесплатный `google_free` неофициальный и может перестать работать или ограничивать запросы.
